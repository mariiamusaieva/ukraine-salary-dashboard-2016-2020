# Аналіз середньомісячної зарплати в Україні (2016–2020 рр.)

Інтерактивний дашборд у **Power BI**, що досліджує динаміку зростання заробітних плат, регіональні відмінності та гендерний розрив в оплаті праці.


## Основні показники (KPI)
**Динаміка зростання (2016–2020):** +53.17%
**Середній гендерний розрив:** ~16.36%
